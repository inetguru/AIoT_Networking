# 제조 현장의 디바이스와 네트워킹 (보조 자료)

수업의 **OPC UA** 실습(`Net2_Intro`)을 이해하기 위한 배경 문서. PLC, 필드버스(Modbus, CANopen, ROS 2), OPC UA, 에지 게이트웨이, 현장의 주의점을 비전공자 눈높이로 설명한다.

- **읽기**: [`index.html`](index.html) 을 브라우저로 연다 (인터넷 연결 없이 동작, 인쇄도 가능)
- `img/` : 그림 파일. `smart_factory_architecture.jpg` 는 AI로 생성한 대표 이미지. 나머지 일러스트 7장은 파일이 있을 때만 문서에 표시된다
- `tools/PROMPTS.md` : 일러스트 생성 프롬프트 (Gemini 앱/AI Studio에서 쓰거나 `gen_images.py`로 생성. 이미지 생성 API는 결제가 필요하다)
- 문서의 도식은 SVG(문서 안에 포함)이며, 설명을 위해 단순화한 것이다.

> 브라우저에서 바로 보려면 GitHub Pages 를 켜면 된다 (Settings → Pages → Branch `main` / folder `/docs`).
